# Ark World

Ark World is a first playable vertical slice for a living settlement simulation and skill-driven economy prototype built in Godot 4.

## Vision

This project is a playful prototype representing the Ark Network principles in a compact, human-scale world:

- Learn by doing
- Work and produce value
- Build relationships and community
- Grow through skills and property ownership
- Create sustainable opportunity in a living world

## Current status

This repository is now initialized as a modular Godot 4 prototype foundation. The first pass includes:

- a playable character controller with walking, running, jumping, and third-person camera
- a stylized low-poly human model that can later be replaced with richer art
- a living settlement scene with NPCs, ground, lighting, and an interaction prompt
- core scripts for player movement, NPC behavior, world setup, and economy/player state scaffolding
- project docs and architecture notes for future iteration

## Run locally

1. Install Godot 4.x.
2. Open the project folder in Godot.
3. Press F5 or run the default scene.
4. Move with WASD, jump with Space, sprint with Shift, and interact with E.

## Design pillars

- Build. Learn. Become.
- Small, coherent world first
- Free and open-source foundations only
- Future-ready architecture for multiplayer expansion

## Project structure

- `scenes/` - playable scenes and world composition
- `scripts/` - core, player, NPC, economy, UI logic
- `docs/` - design and technical documentation
- `assets/` - future art, audio, and procedural content

## Roadmap

- playable movement and camera
- NPC schedule and dialogue foundation
- agriculture and harvesting loop
- market and economy simulation
- property and progression systems
- defense against scope creep while retaining verticality
